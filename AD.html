1. Introducción

El presente informe detalla la implementación manual de un algoritmo de Árbol de Decisión para resolver un problema de clasificación binaria en el sector de telecomunicaciones. El objetivo principal es predecir si un cliente aceptará una oferta de plan de datos móviles, basándose en un conjunto de datos compuesto por 10 registros.

Para ello, se aplican conceptos fundamentales de la teoría de la información, como la entropía y la ganancia de información, con el fin de seleccionar el atributo más relevante que permita segmentar la población de clientes de la manera más pura posible.

Nota metodológica: este es un caso didáctico con un dataset muy reducido (10 registros) y trivialmente separable. Los resultados de precisión del 100% deben interpretarse en ese contexto, y no como una estimación generalizable a datos reales. En el apartado 5 se aclara este punto.

3. Metodología Aplicada

La construcción del árbol de decisión sigue un enfoque descendente (Top-Down) basado en el algoritmo ID3, que utiliza la ganancia de información como criterio de selección.

Cálculo de la Entropía

La entropía mide el desorden o la impureza de un conjunto de datos. Se calcula mediante la siguiente fórmula:

H(S) = - Σ (p_i * log₂(p_i))

Donde p_i representa la proporción de cada clase en el conjunto.

Ganancia de Información

La ganancia de información es la diferencia entre la entropía original y la entropía ponderada después de dividir el conjunto por un atributo. Representa la reducción de la incertidumbre.

Ganancia(S, A) = H(S) - Σ ((|S_v| / |S|) * H(S_v))

El atributo con mayor ganancia se selecciona como nodo de decisión.

Evaluación de Atributos

Atributo: Edad

Se agrupa en Joven (≤30), Adulto (31-50) y Mayor (>50).

  • Joven: 3 no, 0 sí → Entropía = 0
  • Adulto: 4 sí, 2 no → Entropía = 0.918
  • Mayor: 1 sí, 0 no → Entropía = 0

Entropía Ponderada: (3/10)·0 + (6/10)·0.918 + (1/10)·0 = 0.551

Ganancia de Información (Edad): 1.0 - 0.551 = 0.449

Atributo: Tiene Línea Fija

Este atributo divide el conjunto en dos grupos perfectos.

  • Sí: 0 no, 5 sí → Entropía = 0
  • No: 5 no, 0 sí → Entropía = 0

Entropía Ponderada: (5/10)·0 + (5/10)·0 = 0.0

Ganancia de Información (Línea Fija): 1.0 - 0.0 = 1.0

Atributo: Uso de Datos

Se agrupa en Bajo (≤3GB), Medio (3.1-6GB) y Alto (>6GB).

  • Bajo: 3 no, 0 sí → Entropía = 0
  • Medio: 2 no, 2 sí → Entropía = 1.0
  • Alto: 0 no, 3 sí → Entropía = 0

Entropía Ponderada: (3/10)·0 + (4/10)·1.0 + (3/10)·0 = 0.4

Ganancia de Información (Uso de Datos): 1.0 - 0.4 = 0.6

5. Construcción del Árbol de Decisión

Dado que el atributo "Tiene línea fija" obtuvo la ganancia máxima (1.0), se selecciona como raíz del árbol. Este atributo es capaz de separar perfectamente las clases, por lo que no es necesario seguir dividiendo el conjunto.

¿Tiene línea fija?
├── Sí → Aceptó la oferta
└── No → No aceptó la oferta

Métricas del Modelo

  • Precisión: 100% (10/10 casos correctos sobre el conjunto de entrenamiento).
  • Complejidad: Mínima (solo 1 nivel de profundidad).
  • Interpretabilidad: Muy Alta.
Aclaración importante: la precisión del 100% corresponde al rendimiento del árbol sobre los mismos 10 registros con los que fue construido (conjunto de entrenamiento). Al tratarse de un caso trivialmente separable por una única variable, no se realizó una partición train/test. En un escenario real con más datos, sería imprescindible evaluar el modelo sobre un conjunto de prueba independiente y, preferentemente, aplicar validación cruzada para estimar su capacidad de generalización.

6. Conclusiones

La implementación manual del árbol de decisión permitió identificar que la tenencia de línea fija es el predictor más fuerte para la aceptación de la oferta en este conjunto de datos particular. La ganancia de información perfecta (1.0) indica que este atributo elimina por completo la incertidumbre.

Si bien se trata de un caso ideal con pocos datos, el ejercicio refuerza la comprensión de los fundamentos matemáticos detrás de los algoritmos de aprendizaje automático, sentando las bases para abordar problemas más complejos con herramientas como Scikit-learn en el futuro.

Este análisis destaca la importancia de la selección de atributos y cómo una variable correctamente elegida puede simplificar drásticamente un modelo predictivo.

Como trabajo futuro, se propone replicar el ejercicio sobre datasets de mayor tamaño y con clases no perfectamente separables, incorporando métricas adicionales (matriz de confusión, validación cruzada, curvas ROC) que permitan evaluar el desempeño del modelo de manera más realista.
